# 猫猫开心消 · 原创音频重制 V9（制作草案）

状态：制作完成并于 2026-09-10 获用户最终确认。正式运行参数、来源与待真机项见 `audio-runtime-v9.md`。

## 目标与边界

- 为“月夜猫咪花园”建立统一原创声音：温暖、圆润、精致、治愈，面向偏女性休闲用户。
- 消除电子合成感、尖锐高频、廉价手游提示音和写实爆破的突兀感。
- 不模仿或提示模仿任何在世艺人、具体作品或受保护游戏的配乐/音效。
- 保持当前运行架构：两首本地循环 BGM、一个音效精灵、WebAudio 失败回退、音乐/音效独立开关。
- 只替换音频内容，不改变玩法触发逻辑；不新增运行时依赖。
- 旧公开素材在新方案通过真机验收前保留为可回滚版本，不与新素材混用发布。

## 声音品牌

共同音色由以下四层组成：

1. **柔软主体**：毛毡钢琴、拇指琴、木琴、轻拨弦，负责温馨与触感。
2. **猫咪魔法**：音乐盒、钢片琴、细小玻璃铃，负责星光、金币、特殊棋子。
3. **自然动作**：柔和空气掠过、布艺落点、木质轻敲、纸屑和冰晶，负责动作可信度。
4. **克制低频**：软鼓、手拍和低音木块，只用于 PvP 节奏及炸弹冲击，不使用电子低音或轰鸣。

全套避免人声、歌词、明显猫叫、强烈电音、合成器扫频、刺耳金属、高压缩失真和持续低频。短音效必须先有动作信息，再有轻微魔法尾韵；同屏高频触发时仍保持清晰。

## BGM 制作单

### `calm`：月下猫咪花园

- 使用场景：首页、选关、商店、单人闯关及普通结果页。
- 情绪：安全、梦幻、温暖、略带探索感，不催促。
- 速度与结构：约 76–84 BPM，6/8 或轻盈 3/4；主旋律短而易记，避免持续占据注意力。
- 配器：毛毡钢琴主奏，拇指琴/钢片琴点缀，极轻拨弦和空气感环境层；无鼓组，可有很轻的刷奏或木质脉冲。
- 制作要求：无歌词、无人声、首尾可无感循环；不得使用明显电子 pad、EDM 节拍或宏大电影弦乐。
- 交付候选：2 个完整候选；每个源文件 45–70 秒，WAV 44.1 kHz 或更高、无损。

### `battle`：星光爪爪对决

- 使用场景：60 秒好友实时 PvP。
- 情绪：俏皮、轻快、友好竞争，不紧张、不战斗化。
- 速度与结构：约 104–112 BPM，轻盈 4/4；前 2 秒立即建立节拍，循环中保持稳定推动力。
- 配器：拨弦、木琴/拇指琴、软手鼓、低音木块，少量音乐盒星光点；与 `calm` 使用同一音色家族。
- 制作要求：无歌词、无人声、可无感循环；不使用电子鼓、合成器 bass、警报或激烈打击。
- 交付候选：2 个完整候选；每个源文件 45–70 秒，WAV 44.1 kHz 或更高、无损。

入包时从获选源文件制作约 48 秒循环，22050 Hz、单声道 AAC/M4A。两首合计目标不超过 320 KiB，不超过现有 BGM 预算 360 KiB。

## 运行加工与验收

- BGM：检查循环接缝、听感响度、峰值、单声道兼容、前 2 秒识别度和连续播放疲劳度。
- SFX：统一裁切、短淡入淡出、响度配平后合成精灵；精灵目标不超过 48 KiB。
- 混音：在 `calm` 与 `battle` 两首 BGM 下分别试听核心 cue；胜负可以短暂 duck，普通消除不压低 BGM。
- 连消：2–6 连必须感知到逐级增强，但不能靠重复完整音效形成嘈杂堆叠。
- 特殊组合：每次 match payload 只发出一次 `specialCombo`。
- 真机：至少 iOS 与鸿蒙各完成一局单人、一次 2–6 连、三种单特殊、一次特殊组合和一局 PvP。
- 包体：替换后重新执行现有音频测试、开源/素材检查、包体预算与发布门禁。
