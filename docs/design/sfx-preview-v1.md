# 音效试听样带 v1

两份目标文件均为 22050 Hz、16-bit、mono、25.000 秒：

- `sfx-preview-v1.wav`：纯程序化音效。
- `sfx-preview-mixed-v1.wav`：同一 cue 叠加 `match3-wechat/res/audio/calm.m4a` 前 25 秒；基础混音增益为 0.82，胜利/失败各 duck 0.60 秒并在此基础上再降低 15%。

参数：SFX 总线增益 0.34，最多 12 声部，事件合并；无噪声缓冲。点击三变体音高为 0.98/1.00/1.02、音量为 0.94/1.00/1.06。音色使用明亮五声音阶上的毛毡木琴、玻璃铃、柔软水滴、冰晶、软鼓与低音木块。

| 时间 (秒) | Cue |
|---:|---|
| 0.35 / 0.90 / 1.45 | 点击变体 1 / 2 / 3 |
| 2.30 / 2.80 | 交换 / 掉落 |
| 3.35 | 无效 |
| 4.10 / 5.25 | 普通消除 / 连消 |
| 6.70 / 7.75 | 果冻 / 冰块 |
| 8.80 / 9.95 / 11.10 | 火箭 / 彩球 / 炸弹 |
| 11.78 / 12.35 | 锤子 / 购买成功 |
| 13.70 / 14.25 | PvP 释放 / 受击冰冻 |
| 15.00 / 15.60 | PvP 释放 / 受击干扰 |
| 17.10 / 20.00 | 胜利 / 失败 |

生成：`python3 match3-wechat/tools/gen-sfx-preview.py`。混音解码只写 `/tmp` 临时 WAV，不进入小游戏包。
