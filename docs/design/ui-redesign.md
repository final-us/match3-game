## 当前实现策略

- 首页背景使用独立无文字位图 `res/home/moonlit-garden-bg.jpg`，避免把动态数据烘焙进图片。
- 标题、体力、金币和按钮由 Canvas 动态绘制，便于适配不同屏幕与实时数据。
- 对战主视觉使用本轮生成的 `res/home/duel-cats.png`，与首页背景共享同一参考稿和配色约束。
- 首页移除“分享 +1 体力”入口。好友分享仅用于主动邀请对战，不直接发奖励。

## 验收标准

- 375×667、390×844、430×932 三档屏幕无重叠、裁切或底部不可点。
- PvP 主按钮面积与对比度明显高于单人按钮。
- 动态体力、金币和关卡进度不依赖图片内置文本。
- 背景压缩后不出现明显色带，首页新增资源尽量控制在 700KB 内。
- 所有主路径按钮可操作，设置页音乐与音效开关可分别持久化。
