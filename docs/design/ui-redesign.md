# 猫猫开心消 UI 重设计基线

## 已选方向

- 方案：2，月夜猫咪花园。
- 产品名：猫猫开心消。
- 参考稿：`home-reference-moonlit-v1.png`。
- 首屏目标：第一眼确认“治愈猫咪”，第二眼看到“好友对战”，单人闯关作为稳定副循环。

## 当前实现策略

- 首页背景使用独立无文字位图 `res/home/moonlit-garden-bg.jpg`，避免把动态数据烘焙进图片。
- 标题、体力、金币和按钮由 Canvas 动态绘制，便于适配不同屏幕与实时数据。
- 对战主视觉使用本轮生成的 `res/home/duel-cats.png`，与首页背景共享同一参考稿和配色约束。
- 首页移除“分享 +1 体力”入口。好友分享仅用于主动邀请对战，不直接发奖励。

## 游戏内统一（2026-08）

- 正式棋子已切换为 `res/piece1-v2.png` 至 `res/piece5-v2.png`：512×512、透明背景、同一造型比例与月夜边光。
- 单人棋盘和 PvP 共用 `res/game-background-v2.jpg`，关卡地图使用 `res/level-background-v2.jpg`。
- 顶部 HUD、棋盘、道具栏、商店、设置和结算统一使用深靛蓝玻璃、薰衣草紫、樱花粉与暖金描边；首页体力、金币、商店、设置均为独立控件。
- 关卡地图每屏固定显示 5 个由近及远的猫耳圆形节点，第 5 个节点停在背景亭子前；最多预览已解锁关之后 4 关，随通关持续生成，不设置末端文案。
- 当前关、已完成和未解锁节点使用三张同构透明位图，中心关卡号与星级由 Canvas 动态排版，素材记录见 `generated-assets/README.md`。
- 首页 HUD、商店、单人棋盘、结算和 PvP 使用同一中文与数字字体回退、居中基线和自适应字号规则；动态长数字必须在控件安全区内缩小，不能依赖固定字符宽度。
- 特殊棋子保留猫咪底图，叠加原创猫爪光束/魔法炸弹运行图和 Canvas 触发动画；鸿蒙降效时保留静态识别层并缩短动画。
- 三个基础道具、单人结算猫咪、金币、步数和计时图标均使用同一生成批次，详细记录见 `generated-assets/README.md`。
- 鸿蒙设备继续启用较低 DPR 和关闭碎屑粒子，静态高精度素材不改变该降效策略。
- 首次单人操作、首次生成特殊棋子、首次遇到障碍、首次拥有单人道具及首次进入 PvP 等待页使用同一玻璃卡片 Canvas 引导；每项只显示一次，可跳过，不增加位图素材。单人引导显示期间暂停关卡计时。
- 开发者工具验收截图：`devtools-home-v2.png`、`devtools-gameplay-v2.png`。

## 验收标准

- 375×667、390×844、430×932 三档屏幕无重叠、裁切或底部不可点。
- PvP 主按钮面积与对比度明显高于单人按钮。
- 动态体力、金币和关卡进度不依赖图片内置文本。
- 背景压缩后不出现明显色带，首页新增资源尽量控制在 700KB 内。
- 所有主路径按钮可操作，设置页音乐与音效开关可分别持久化。
