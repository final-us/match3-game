# 双人对战四道具规则

日期：2026-09-26。状态：用户已确认四道具、自由分配5次免费额度、共享10秒冷却及下方效果，鼓舞指定为5秒2倍得分。用户随后明确“开始实现”，授权下方本地开发顺序。现已完成本地实现、联调与独立逻辑复核，等待用户界面验收和微信双账号真机验证；未部署或上传。

## 已确认

- 道具为冰冻、干扰、反弹、鼓舞；反弹替代守护泡泡。
- 每局开局提供5个免费额度；每10秒最多主动使用一个道具，四种共享限制。
- 道具名称统一为四字：冰霜冻结、四连魔咒、镜面反弹、猫咪鼓舞。
- 彩虹染色、星星收藏、连消挑战不进入本方案，用户认为与鼓舞功能接近。
- 既有60秒对战不变；受击提示已确认冰冻中央提示、干扰中央仅1秒后保留边缘状态。

## 已确认的效果与携带规则

- 等待页将5次额度自由分配给四种道具，每次消耗1额度，允许重复携带；不采用之前未确认的“只带两种/每种最多两次”。准备后锁定配置，取消准备后调整。
- 冰霜冻结：保留冻结3秒。四连魔咒：保留5秒内至少4连才能消除。
- 镜面反弹：主动开启5秒防护，抵挡并反弹下一次冰冻或干扰；触发一次即结束，未触发则到期。反弹攻击不得再次反弹，也不消耗防守者第二次额度或重置其主动使用冷却；再次反弹的防护按只抵挡处理，避免无限往返。只有主动开启计入10秒限制。
- 猫咪鼓舞：开启后5秒内消除得分为2倍，本身不直接送分。用户已明确替换此前1.5倍草案；尚无数值平衡试玩证据。

## 实现边界

- 冻结期间不能主动使用道具；已开始的连锁可继续结束。效果按服务端绝对时刻到期，同类攻击取较晚结束时刻，不累加持续时间；反弹只处理一次，鼓舞窗口为左闭右开5秒。每次消除结束时记录原始累计分，开启鼓舞前积压分数先确认，再授予倍率；重试不重复扣次数或得分。
- 保留房间协议2，新房增加itemRulesVersion=3；旧房继续旧规则，旧客户端不能加入四道具房。具体字段与失败恢复见[客户端合同](../contracts/pvp-items-v3.md)。
- 倍率窗口、额度、冷却与回合由服务端校验，但消除原始分与时间仍由客户端报送并做合理性校验，不等于服务端完整重演棋盘。最低往返延迟的中点校时减少慢回包影响，不能完全消除非对称网络误差。最后800毫秒及时提交新增分；网络延迟导致到局末后才收到的样本仍不计入本局。
