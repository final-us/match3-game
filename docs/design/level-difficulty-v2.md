# 单人 20 关难度与限时基线

> 历史文档：该固定 20 关方案已由 [`level-difficulty-v3.md`](level-difficulty-v3.md) 的确定性无限关卡模型取代，仅保留为标定记录。

## 设计原则

- 第 1 关只教学，不限时；第 2–5 关 180 秒，第 6–10 关 165 秒，第 11–15 关 150 秒，第 16–20 关 135 秒。
- 限时从首个有效交换完整处理后开始；退到后台期间暂停。目标完成与超时落在同一帧时，目标完成优先。
- 同一关连续完整失败 2 次后，下一次尝试获得 `+3` 步和 `+20` 秒；成功后清零。一次尝试内重复广告复活不会重复累计连败。
- 激励视频复活保持既定商业化规则：每次完整观看增加 `+5` 步；限时关同时增加 `+30` 秒；单局不限次数。
