## 面向玩家的简短说明

> 焕新月夜猫咪主题界面，优化好友对战房间、结算卡、商店和每日挑战展示；完善双方头像与道具冷却提示。优化启动资源和首页数据读取，减少运行负担；改进广告异常提示，并完善体验分析及隐私保护说明。

## 详细说明

- **画面更统一**：更新备战双猫、平局猫咪、签到第7天插画与花饰金边；统一主要操作、退出及广告按钮的颜色和材质，完善不同屏幕下的信息排版。
- **好友对战更清楚**：准备页保留双猫插画及双方小头像/猫咪名称；主动选择分享头像后，可在房间、对局与结算中辨认双方。完善独立冷却的状态展示，保留现有四种道具及规则。
- **商店更易操作**：购买和广告领取按钮上下排列，道具位置向内调整；短屏可滚动查看商品，滑动时取消购买和广告点击，减少误触。
- **每日页面更协调**：精修每日挑战及签到、任务、周宝箱的猫咪/花框/按钮细节；签到提示与累计规则保持一致。任务仍须玩家主动领取，不更改现有奖励数值。
- **新笑脸小猫**：商店、每日任务与七日签到共用新绘制的微笑小猫页头，替换原来的低落表情。
- **领奖保持当前页面**：进入及领取过程中保留原页面，等待时锁定领取操作；可靠到账后轻提示。真正未确认或保存失败时提供重试，已入账但回执待同步时继续保留页面。
- **局内设置**：单人棋盘增加设置入口，可暂停倒计时、开关音乐与音效、继续游戏或确认返回首页。入口位于状态栏上方左侧，按微信胶囊实际位置对齐，保留原有数据栏和棋盘排版；移除旁边“单人闯关”小标题。
- **降低启动与首页负担**：排除未使用的按钮运行资源，共用相同背景图片对象，缓存首页体力和金币展示；实际扣款、发奖与恢复仍校验持久化数据。未取得最新双平台耗时对照，不承诺“减少几秒”。
- **广告反馈更明确**：区分提前关闭、暂无广告、加载/展示失败和回调超时等提示；正式版不展示开发诊断。沿用完整观看、可靠保存和避免重复发奖的规则。
- **完善体验分析**：接入微信官方首页入口、普通关卡和启动分析；未开放的首次消除/引导过程远端指标仍关闭，不自建统计后台。隐私指引需与最终采用的功能和微信后台声明一致。
